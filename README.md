# קום! (boker-web)

אפליקציית שעון מעורר שרצה בדפדפן (PWA). השעון לא שותק עד שמבצעים משימה: שכיבות סמיכה מול המצלמה, תרגיל חשבון, אמירת "מודה אני" בקול רם, או צילום המברשת בחדר האמבטיה.

הרעיון מבוסס על האפליקציה "בוקר שוקר" (https://bokershoker.com/). הפרויקט הזה הוא גרסת web עצמאית, ללא חנות אפליקציות.

> סטטוס: גרסה ראשונית (v1). PWA עובד, וה-Worker כתוב ונבדק מקומית. ראו [docs/deploy.md](docs/deploy.md) לפריסה.

אתר חי: https://idanatwork.github.io/boker-web/

## סיכום בשורה

PWA מותקן למסך הבית + Web Push משרת על Cloudflare Workers (Cron כל דקה, KV לנתונים). כשהשעון מגיע, השרת שולח פוש, ובהמשך שולח שוב ושוב עד שהמשתמש פותח את האפליקציה. בתוך האפליקציה השעון מצלצל ונועל את המסך עד סיום המשימה. מצב Wake Lock הוא גיבוי למי שמשאיר את הטלפון דלוק על המטען עם האפליקציה פתוחה.

## החלטות מפתח

1. אין צורך בחנות אפליקציות. התקנה דרך "הוסף למסך הבית".
2. אין התראות מקומיות מתוזמנות ב-web, ולכן הצלצול ברקע תלוי ב-Web Push מהשרת.
3. צליל ההתראה הוא צליל מערכת רגיל. צליל רציף וארוך אפשרי רק בשלב ב' (עטיפת Capacitor).
4. הכול חינם בשכבת ה-free של Cloudflare בהיקף אישי.
5. אין חשבונות משתמש בשלב א'. זיהוי לפי מנוי ה-push (מזהה מכשיר אקראי).
