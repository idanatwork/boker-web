# זרימות

## 1. הרשמה ל-push (פעם אחת)
1. המשתמש פותח את האתר ב-Safari ומתקין למסך הבית (iOS). Android ו-Desktop: כפתור התקנה.
2. פותח את האפליקציה המותקנת.
3. לוחץ "הפעל התראות". רק מתוך לחיצה, כי iOS דורש מחוות משתמש.
4. `Notification.requestPermission()` ואז `registration.pushManager.subscribe({ userVisibleOnly:true, applicationServerKey: VAPID_PUBLIC })`.
5. הלקוח שולח את המנוי ל-`POST /api/register`. השרת שומר ומחזיר deviceId ו-deviceToken.
6. הלקוח מבקש פוש בדיקה ומציג הצלחה.

## 2. יצירת שעון
1. מסך "שעון חדש": שעה, ימים, משימות, צליל.
2. `PUT /api/alarms/:id`.
3. השרת שומר ומעדכן את `idx:{dow}:{HHMM}` לכל יום פעיל.
4. הלקוח שומר עותק מקומי למצב לא מקוון.

## 3. פוש מסלים עד פתיחה
Cron בכל דקה:
1. השרת בונה את מפתחות `idx` לדקה הנוכחית (לפי tz של כל שעון).
2. לכל שעון תואם: יוצר `ring:*` ושולח פוש #1.
3. אם `ring:*` קיים ועדיין לא כובה, שולח פוש חוזר לפי הטבלה:

| זמן מהצלצול | תדירות |
|---|---|
| 0 עד 5 דקות | כל דקה |
| 5 עד 20 דקות | כל דקה, עם טקסט דחוף יותר |
| 20 דקות עד שעתיים | כל 5 דקות |
| אחרי שעתיים | נעצר, נרשם "לא כובה" |

4. כל פוש עם אותו `tag`, כך שההתראה מוחלפת ולא נערמת, ו-`renotify` מצלצל מחדש.
5. נפתחה האפליקציה: ההתראה נסגרת, מסך הצלצול מתחיל. הלקוח קורא ל-`/api/ring/:id/opened` והשרת מעביר את הפוש לתדירות איטית עד כיבוי מלא (למקרה שהמשתמש סוגר ונרדם).

## 4. משימה וכיבוי
1. מסך הצלצול מנגן צליל בלולאה ומציג את המשימה הבאה.
2. המשתמש מבצע את המשימה (ראו product.md). בכל משימה יש אישור הצלחה בצד לקוח.
3. אחרי כל המשימות: `POST /api/ring/:id/dismiss`. השרת מוחק `ring:*`, רושם סטטיסטיקה ומעדכן רצף.
4. הלקוח מציג סיכום: זמן תגובה, רצף נוכחי.
5. אם אין רשת: הלקוח שומר את הכיבוי בתור ושולח כשחוזרת. הפוש הבא עלול להגיע לפני כן, ולכן ב-service worker בודקים מצב מקומי "כובה" ומדלגים על ההצגה.

## 5. נודניק
`POST /api/ring/:id/snooze` מעביר את `nextAt` קדימה במרווח שהוגדר. הפוש ממשיך אחרי ההמתנה.

## 6. מצב Wake Lock
1. המשתמש מפעיל "מצב לילה" והאפליקציה נשארת פתוחה על המטען.
2. הדף מבקש Wake Lock ומחזיק טיימר מקומי לשעון הקרוב.
3. בזמן השעון הדף מנגן את הצלצול בעצמו, בלי תלות בשרת. השרת עדיין שולח פוש כגיבוי.
4. כשהדף חוזר ממצב נסתר, מבקשים מחדש Wake Lock.
