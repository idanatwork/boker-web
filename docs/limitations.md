# מגבלות ידועות

## iOS (הסיכון העיקרי)
- Web Push עובד רק ב-PWA שהותקן למסך הבית (iOS 16.4 ומעלה), ורק אחרי אישור המשתמש.
- ההתקנה ידנית: שיתוף, "הוסף למסך הבית". אין דרך להפעיל אותה מתוך הקוד.
- הצליל הוא צליל התראה רגיל של המערכת, קצר. אי אפשר לנגן צליל ארוך או בלולאה ברקע.
- מצב "נא לא להפריע" ו-Focus עלולים להשתיק התראות. יש להנחות את המשתמש להוסיף את האפליקציה לרשימת היוצאים מן הכלל.
- מצב חיסכון בסוללה עלול לעכב משלוח.

## כללי web
- אין התראות מקומיות מתוזמנות. אין API שמעיר את המכשיר בשעה מסוימת.
- טיימרים בדף מוקפאים כשהדף ברקע או כשהמסך כבוי, ולכן אי אפשר להסתמך על `setTimeout`.
- דפדפנים חוסמים צליל אוטומטי בלי מחוות משתמש. מסך הצלצול מנגן אחרי שהמשתמש פתח את האפליקציה מהתראה, וזה בדרך כלל נחשב מחווה.
- אי אפשר לחסום מהמשתמש לצאת מהאפליקציה או לכבות את ההתראה.

## דיוק
- משלוח push הוא best-effort. עיכוב של שניות עד דקות אפשרי. Cron של Cloudflare מדויק לרמת הדקה בלבד.
- בגלל זאת מומלץ להשתמש בשעון המערכת כגיבוי בשבועות הראשונים.

## חישוב משימות
- ספירת שכיבות סמיכה לפי מצלמה אינה מושלמת: תאורה וזווית משפיעות. יש מצב כיול וכפתור "ספרתי ידנית" שמופעל אחרי כמה כשלונות.
- זיהוי דיבור (Web Speech API) לא נתמך אחיד, ולכן "מודה אני" נמדד לפי עוצמה ומשך ולא לפי תוכן.
- מודלי TensorFlow.js כבדים ויש לטעון אותם מראש ולשמור במטמון.
