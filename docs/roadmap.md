# Roadmap

## שלב 0: הוכחת היתכנות (חובה לפני הכול)
- [x] Worker עם Cron דקתי ששולח פוש (נבדק מקומית מקצה לקצה, כולל פענוח ההצפנה).
- [x] מימוש Web Push עצמאי על WebCrypto (בלי ספרייה), עם בדיקות. עדיין לאמת מול APNs אמיתי.
- [ ] בדיקה על iPhone אמיתי: PWA מותקן, שעה בלילה, מסך נעול, חיסכון בסוללה, Focus.
- [ ] מדידת עיכוב ממוצע בין השעה המתוכננת להצגת ההתראה.
- החלטת go/no-go: אם העיכוב או השקט לא מקובלים, לעבור ישר לשלב ב'.

## שלב א': MVP (web)
1. מבנה ריפו, manifest, service worker, התקנה.
2. רישום push ו-API לשעונים (KV).
3. מסך צלצול ונודניק.
4. משימות: חשבון (הקל), אחר כך מודה אני בעוצמת קול.
5. משימות מצלמה: שכיבות סמיכה, צילום המברשת.
6. רצף ימים וסטטיסטיקות.
7. מצב Wake Lock.
8. מסך הסבר להתקנה ולהגדרת Focus.
9. בדיקות: unit למשימות ולתזמון, e2e עם Playwright (service worker מדומה), בדיקת ידנית על iOS ו-Android.

## שלב ב': עטיפת Capacitor
- אפליקציה מקורית עטופה סביב אותו קוד web.
- התראות מקומיות מתוזמנות (LocalNotifications), צליל רציף, Critical Alerts (דורש הרשאת Apple מיוחדת).
- Background audio לצליל ארוך.
- פרסום ב-TestFlight, אחר כך App Store ו-Play.
- דרישות: חשבון Apple Developer בתשלום ומכשיר Mac לבנייה.

## שלב ג': רעיונות
- חשבונות וסנכרון בין מכשירים.
- משימות נוספות (סריקת ברקוד, צעדים).
- ערכות צלילים, אתגרים עם חברים.

## קריטריוני קבלה למעבר שלב א'
- הצלצול הראשון מגיע בתוך דקה מהשעה ב-95% מהלילות בבדיקה של שבועיים.
- אפשר להתקין, להגדיר שעון ולכבות אותו בעזרת משימה בפחות מחמש דקות מאפס.
